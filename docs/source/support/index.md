# Getting Help

ForkForward Cargo is maintained by ForkForward. The MassTransit project and Massient, Inc. are not responsible for this
code, so don't take problems with it to their channels.

## Questions and bugs

Open an [issue](https://github.com/ForkForward/dotnet-cargo/issues) in the repository of this fork. Include:

- the names and versions of the ForkForward Cargo packages,
- the transport and the .NET version,
- the smallest code that shows the problem, and the whole exception with its stack trace.

Look at [Common Mistakes](common-mistakes.md) first. [Show Configuration](show-configuration.md) prints how the bus is
configured, which answers most questions about endpoints and topology.

## Security problems

Follow the [security policy](https://github.com/ForkForward/dotnet-cargo/blob/develop/SECURITY.md) of the repository.

## Contributing

Pull requests go to the `develop` branch of [ForkForward/dotnet-cargo](https://github.com/ForkForward/dotnet-cargo).

## MassTransit 9 and commercial support

MassTransit 9, new features from the original authors and commercial support come from the official MassTransit, at
[masstransit.io](https://masstransit.io), not from this fork.

## Videos

The MassTransit project has published several seasons of videos
[on YouTube](https://www.youtube.com/playlist?list=PLx8uyNNs1ri2MBx6BjPum5j9_MMdIfM9C). They use the original packages
and different versions of MassTransit; check which version a video shows before following it.
